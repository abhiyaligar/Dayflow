# Product Requirements Document (PRD): Dayflow - Human Resource Management System

## 1. Introduction & Overview
### 1.1 Purpose
The purpose of the Dayflow Human Resource Management System (HRMS) is to digitize, centralize, and streamline core human resource and employee operations. The system aims to simplify workflows for onboarding, profile management, daily/weekly attendance, leave requests, and payroll tracking.

### 1.2 Scope
Dayflow includes:
*   Secure custom email/password authentication & role-based authorization.
*   Interactive dashboards customized for Employees and Admins/HR Officers.
*   Profile management with role-based editing permissions.
*   Attendance tracking with daily/weekly logs and check-in/check-out functionality.
*   Time-off request submission and approval workflow.
*   Basic payroll and salary structure visibility.

---

## 2. User Classes and Characteristics
The system has two primary roles:

| User Role | Description | Core Capabilities |
| :--- | :--- | :--- |
| **Admin / HR Officer** | Manages organization-wide settings, employee data, and requests. | Employee onboarding (creation of profiles, usernames, and initial passwords), profile edits, attendance tracking, leave request approvals, payroll management. |
| **Employee** | Regular team members tracking their own details. | View profile, edit personal contact details, check-in/out, request leaves, view payslips/salary details. |

## 3. Functional Requirements

### 3.1 Authentication & Authorization

#### 3.1.1 Employee Onboarding & Account Creation
*   **Restriction**: Normal users **cannot self-register**. Account creation is restricted entirely to Admins and HR Officers.
*   **Automatic Login ID Generation**: The Login ID (Employee ID) is automatically generated by the system when a new employee is onboarded.
    *   **Format**: `[First 2 letters of first name][First 2 letters of last name][Year of joining][Serial number of joining]`
    *   *Example*: For John Doe joining in 2026 as the 5th employee of that year, the Login ID is `JODO2026005`.
*   **Initial Password**: The system automatically generates a secure initial password for the newly created account.
*   **Password Change**: Upon logging in for the first time with the system-generated password, employees can change their password to a custom secure password of their choice.

### 3.2 Dashboards & Status Indicators

#### 3.2.1 Employee Dashboard
*   Displays quick-access links/cards: Profile, Attendance, Leave Requests, Logout.
*   Shows recent activity or alert feeds.

#### 3.2.2 Admin / HR Dashboard
*   Consolidated directory of employee cards.
*   **Employee Cards & Status Indicators**:
    *   Each card displays the employee's profile picture and basic details.
    *   At the top-right corner of each card, a status indicator shows the employee's current attendance or work status:
        *   🟢 **Green dot**: Present (Employee is checked-in and present in the office).
        *   ✈️ **Airplane icon**: On Leave (Employee has an approved leave request for the current day).
        *   🟡 **Yellow dot**: Absent (Employee has not checked-in and has not applied for time-off for the current day).

### 3.3 Employee Profile Management
*   **View Profile**:
    *   Displays: Personal details (Name, Address, Phone, Profile Picture), Job details (Designation, Department, Date of Joining), Salary structure, and uploaded Documents.
*   **Edit Profile**:
    *   Employees can update limited personal details: Phone, Address, and Profile Picture.
    *   Admins/HR Officers have full edit permissions to modify all fields, including designation, salary structure, and status.

### 3.4 Attendance Management
*   **Tracking & Actions**:
    *   Check-in and Check-out buttons for employees to mark work hours.
    *   Attendance status types: `Present`, `Absent`, `Half-day`, `Leave`.
*   **Employee View**:
    *   By default, the Attendance page displays a day-wise calendar view of their own attendance for the **ongoing month**.
    *   Displays detailed logs based on their working time, including break intervals.
    *   Employees can only view their own attendance records.
*   **Admin / HR View**:
    *   Can see the real-time attendance logs of **all employees present on the current day**.
    *   Search and filter attendance history for all employees.

### 3.5 Leave & Time-Off Management
*   **Permissions**:
    *   Employees can **view only their own** time-off/leave records and apply for new leaves.
    *   Admins and HR Officers can view time-off records for all employees and approve or reject them.
*   **Leave Application (Employee)**:
    *   Select type: `Paid`, `Sick`, `Unpaid`.
    *   Select date range (Start Date to End Date).
    *   Add optional remarks.
    *   Leave status progression: `Pending` -> `Approved` OR `Rejected`.
*   **Leave Approval (Admin / HR)**:
    *   Consolidated list of pending leave requests.
    *   Approve or reject requests with comments.
    *   Status updates propagate immediately to employee records and attendance sheets.

### 3.6 Payroll / Salary Management

#### 3.6.1 Salary Information Management (HR/Admin Panel)
*   **Salary Definition**: Allows Admin/HR to define and manage all salary-related details, including wage type (Fixed Wage), working schedule, components, and benefits.
*   **Auto-Calculated Salary Components**:
    When a Fixed Wage (e.g. ₹50,000 or ₹250,000) is specified, the system automatically computes individual salary components based on the following breakdown:
    *   **Basic Salary**: 50% of the defined Wage.
    *   **House Rent Allowance (HRA)**: 50% of the computed **Basic Salary** (i.e. 25% of Wage).
    *   **Standard Allowance**: 8.33% of the defined Wage.
    *   **Leave Travel Allowance (LTA)**: 8.33% of the defined Wage.
    *   **Performance Bonus**: A defined fixed amount or percentage.
    *   **Fixed Allowance**: Calculated automatically as the remaining balance (`Wage - (Basic + HRA + Standard + LTA + Performance Bonus)`). The sum of all components must equal the defined total Wage.
*   **Real-time Auto-Updates**: If the total Wage is modified, all salary components auto-update instantly.
*   **Tax & Benefit Deductions**:
    *   **Provident Fund (PF)**: Calculated at 12% of the computed **Basic Salary**.
    *   **Professional Tax (PT)**: Fixed at ₹200.

#### 3.6.2 Attendance-Based Payslip Generation
*   Attendance data serves as the direct source of truth for monthly payslip calculation.
*   The system computes the total number of payable days using generated attendance records.
*   **Deductions**: Any unpaid leave or missing attendance days (unexcused absences) automatically reduces the number of payable days during payslip computation.
*   **Employee View**:
    *   Read-only access to salary details, monthly base, allowances, deductions, and tax configurations.
*   **Admin Control**:
    *   Consolidated list of payroll details for all employees.
    *   Ability to update salary structures.
